\# Детальная спецификация вариантов использования (Use Cases)



\## Акторы (Действующие лица)

1\. \*\*Пользователь (Player/User)\*\* – физическое лицо, взаимодействующее с интерфейсом: создаёт финансовые цели, вносит пополнения, просматривает прогресс.

2\. \*\*Внешний сервис курсов валют (Currency Rate Service)\*\* – опциональная внешняя система, предоставляющая актуальный курс для пересчёта цели в другую валюту.

3\. \*\*Системный таймер ОС (System Timer)\*\* – системный триггер, инициирующий проверку условий напоминания о пополнении.



\---



\## UC-1: Создать цель

\* \*\*Краткое описание:\*\* Пользователь создаёт новую финансовую цель.

\* \*\*Предусловия:\*\* Приложение запущено, открыт главный экран.

\* \*\*Основной поток:\*\*

&#x20; 1. Пользователь нажимает кнопку «+ Новая цель».

&#x20; 2. Система открывает форму создания цели.

&#x20; 3. Пользователь вводит название, целевую сумму, дату достижения и категорию.

&#x20; 4. Система валидирует поля (название не пустое, сумма > 0, дата в будущем).

&#x20; 5. Система сохраняет цель в локальное хранилище.

&#x20; 6. Главный экран обновляется и отображает новую карточку цели.

\* \*\*Альтернативный поток А1 (Ошибка валидации):\*\* На шаге 4 данные некорректны. Система подсвечивает поля с ошибками, форма остаётся открытой.

\* \*\*Постусловия:\*\* Цель сохранена в базе данных и видна в списке целей.



\---



\## UC-2: Внести пополнение

\* \*\*Краткое описание:\*\* Пользователь вносит сумму в накопления по выбранной цели.

\* \*\*Предусловия:\*\* В системе существует хотя бы одна созданная цель.

\* \*\*Основной поток:\*\*

&#x20; 1. Пользователь открывает экран цели и нажимает «Пополнить».

&#x20; 2. Система открывает форму пополнения.

&#x20; 3. Пользователь вводит сумму, дату и комментарий.

&#x20; 4. Система валидирует данные (сумма > 0, дата не в будущем).

&#x20; 5. Система сохраняет запись о пополнении в историю.

&#x20; 6. Система пересчитывает накопленную сумму, остаток, процент прогресса и ежемесячный взнос.

&#x20; 7. Обновляются шкала прогресса и отметки вех (25/50/75/100%).

\* \*\*Альтернативный поток А1 (Неверная сумма):\*\* Сумма ≤ 0. Система выводит сообщение об ошибке, форма остаётся открытой.

\* \*\*Постусловия:\*\* Накопления увеличены, запись добавлена в историю, прогресс пересчитан.



\---



\## UC-3: Просмотреть прогресс

\* \*\*Краткое описание:\*\* Пользователь просматривает детальную статистику по цели.

\* \*\*Предусловия:\*\* Цель существует.

\* \*\*Основной поток:\*\*

&#x20; 1. Пользователь открывает экран цели.

&#x20; 2. Система отображает название, целевую сумму, накоплено, остаток, процент, шкалу с вехами, план по месяцам и историю пополнений.

\* \*\*Постусловия:\*\* Состояние системы не изменяется (операция только для чтения).



\---



\## UC-4: Редактировать / удалить цель

\* \*\*Краткое описание:\*\* Пользователь изменяет параметры цели или удаляет её.

\* \*\*Предусловия:\*\* Цель существует.

\* \*\*Основной поток:\*\*

&#x20; 1. Пользователь выбирает действие «Редактировать» или «Удалить».

&#x20; 2. При редактировании открывается форма с заполненными полями. При удалении запрашивается подтверждение.

&#x20; 3. Система сохраняет изменения (или удаляет цель вместе с её историей пополнений).

\* \*\*Альтернативный поток А1 (Отмена удаления):\*\* Пользователь отменяет подтверждение — цель остаётся без изменений.

\* \*\*Постусловия:\*\* Данные цели обновлены или цель удалена из хранилища.



\---



\## UC-5: Просмотреть сводку

\* \*\*Краткое описание:\*\* Пользователь видит общую картину по всем своим целям.

\* \*\*Предусловия:\*\* Приложение запущено.

\* \*\*Основной поток:\*\*

&#x20; 1. Система загружает все цели из хранилища.

&#x20; 2. Система вычисляет суммарный прогресс по всем целям.

&#x20; 3. Система определяет ближайшую по дате активную цель.

&#x20; 4. Система отображает карточки целей и сводные показатели.

\* \*\*Постусловия:\*\* Состояние системы не изменяется.



\---



\## UC-6: Получить напоминание о пополнении (Системный таймер)

\* \*\*Краткое описание:\*\* Система напоминает пользователю о необходимости пополнить активную цель.

\* \*\*Предусловия:\*\* Существует активная цель, с последнего пополнения которой прошло более 30 дней.

\* \*\*Основной поток:\*\*

&#x20; 1. При открытии главного экрана системный таймер инициирует проверку дат последних пополнений.

&#x20; 2. При выполнении условия система выводит ненавязчивое уведомление на экране.

\* \*\*Постусловия:\*\* Уведомление отображено, данные не изменяются.
