\# Глоссарий проекта GoalJar («Копилка целей»)



| Термин (EN/RU) | Определение и контекст использования |

| :--- | :--- |

| \*\*Goal (Цель)\*\* | Запись пользователя: название, целевая сумма, дата достижения, опционально категория и описание. Основная доменная сущность приложения. |

| \*\*Deposit (Пополнение)\*\* | Ручная запись о внесённой сумме с датой и комментарием, которая увеличивает накопления по выбранной цели. |

| \*\*Accumulated (Накоплено)\*\* | Суммарная величина всех пополнений по конкретной цели на текущий момент времени. |

| \*\*Target Amount (Целевая сумма)\*\* | Сумма денежных средств, которую пользователь планирует накопить к дате достижения цели. |

| \*\*Progress (Прогресс)\*\* | Отношение накопленной суммы к целевой, выражаемое в процентах и в денежном эквиваленте. |

| \*\*Milestone (Веха)\*\* | Порог прогресса (25%, 50%, 75%, 100%), отмечаемый визуально на шкале для повышения мотивации пользователя. |

| \*\*Monthly Contribution (Ежемесячный взнос)\*\* | Расчётная величина: остаток до целевой суммы, делённый на число месяцев до даты достижения (с округлением вверх). |

| \*\*Active Goal (Активная цель)\*\* | Цель, дата достижения которой ещё не наступила, а накопленная сумма меньше целевой. |

| \*\*Overdue Goal (Просроченная цель)\*\* | Цель, дата достижения которой прошла, но необходимая сумма так и не была накоплена. |

| \*\*Completed Goal (Достигнутая цель)\*\* | Цель, накопленная сумма по которой больше или равна целевой сумме. |

| \*\*Repository (Хранилище)\*\* | Локальный файл SQLite (или JSON), в котором сохраняются данные о целях и пополнениях между запусками приложения. |

| \*\*Summary Screen (Сводный экран)\*\* | Главный экран приложения со списком всех целей, суммарным прогрессом и ближайшей по дате целью. |

| \*\*MVC (Model-View-Controller)\*\* | Архитектурный паттерн разделения ответственности: модель (данные и бизнес-правила), представление (JavaFX UI), контроллер (обработчики действий). |
