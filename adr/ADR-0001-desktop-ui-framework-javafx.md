
# ADR-001: Выбор графического фреймворка JavaFX для настольного клиента



## Контекст и постановка задачи



Настольный клиент приложения «Копилка целей» (GoalJar) должен работать на операционных системах Windows 10/11, macOS 12+ и Ubuntu 22.04+ (REQ-PORT-001), обеспечивать визуализацию прогресса накоплений с вехами 25/50/75/100% (REQ-FUNC-005), поддерживать ввод с клавиатуры (REQ-INT-004), корректно отображаться на экранах от 1024×720 (REQ-INT-005) и выполнять экспорт в CSV (REQ-INT-007). Необходимо выбрать технологический стек разработки графического интерфейса в экосистеме Java 17+.



## Драйверы решения



- Поддержка современных стандартов UI, стилизации через CSS и декларативной разметки (FXML).

- Наличие встроенных компонентов визуализации (ProgressBar для шкалы прогресса).

- Кроссплатформенность без перекомпиляции под каждую настольную ОС.

- Изоляция UI-слоя от бизнес-логики и работы с базой данных (CON-06).

- Нулевая стоимость лицензий и открытый исходный код (CON-07).



## Рассмотренные варианты



1. JavaFX 21+ с FXML и CSS-стилизацией.

2. Библиотека Swing с ручной отрисовкой кастомных шкал прогресса.

3. Web-оболочка на Electron с оберткой над локальным веб-интерфейсом.



## Итог решения



Выбран вариант 1. Графический интерфейс реализуется на JavaFX 21+. Разметка экранов выносится в FXML-файлы, стили оформляются в CSS, а для построения шкалы прогресса используется штатный компонент `ProgressBar`. Все расчёты прогресса и прогноза выполняются в фоновых потоках `javafx.concurrent.Task` с обновлением интерфейса в потоке JavaFX Application Thread.



### Последствия



- Для запуска приложения требуется наличие модулей JavaFX или упаковка дистрибутива через утилиту `jpackage` с встроенным runtime (REQ-INST-001).

- Стилизация через CSS обеспечивает единообразный внешний вид.

- Встроенные компоненты закрывают требования REQ-FUNC-004 и REQ-FUNC-005 без подключения сторонних библиотек.



### Подтверждение



Тесты проверяют запуск главного окна на эталонных разрешениях от 1024×720, корректную отрисовку шкалы прогресса и вех при различных значениях накоплений, а также отзывчивость интерфейса при работе с базой данных.



## Плюсы и минусы вариантов



| Вариант | Плюсы | Минусы |

|---|---|---|

| JavaFX 21+ | Встроенные компоненты, FXML, стилизация CSS, нативная скорость | Требует модулей JavaFX при сборке |

| Swing | Входит в стандартную поставку JDK | Устаревший API, нет встроенных современных компонентов |

| Electron | Гибкая веб-верстка | Большой размер дистрибутива (>150 МБ), высокое потребление ОЗУ |
